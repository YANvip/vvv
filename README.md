# 网店售后中台

用于网店补发、换货、退件记录和打单协作的售后中台。

## 核心能力

- 客服一句话录入售后需求。
- 自动识别订单平台、订单号、售后类型、商品型号、数量、颜色。
- 打单员填写或扫码录入补发快递单号。
- 管理员维护商品型号、颜色、人员和权限。
- 后期接入飞书多维表格、飞书机器人、微信小程序、拼多多/抖店开放平台。

## 当前阶段

这是正式项目骨架，准备替换服务器上的临时原型。

## 目录

- `apps/api`：后端 API 和识别规则。
- `apps/web`：前端工作台。
- `docs`：产品和部署文档。
- `infra`：Docker Compose、数据库初始化、部署配置。
