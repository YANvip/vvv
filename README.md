# 网店售后工作台 1.0

面向客服、打单员和管理员的补发、换货、退件协作系统。

## 已交付功能

- 客服一句话识别平台、订单号、售后类型、商品、数量和颜色。
- 识别结果可人工确认修改，再创建售后单。
- 重复订单提醒，必要时可确认重复建单。
- 售后记录搜索、平台/类型/状态筛选和 CSV 导出。
- 打单员可用扫码枪录入快递单号，保存后自动完成售后单。
- 售后详情修改、状态流转和操作日志。
- 管理员创建客服、打单员、管理员账号并控制启停。
- 管理员维护商品型号、别名、颜色和颜色必填规则。
- PostgreSQL 持久化，旧版数据库启动时自动补齐新表和字段。

## 角色权限

- 客服：识别并创建售后单、查询和修改记录。
- 打单员：查询记录、扫码或输入补发快递单号。
- 管理员：全部功能，以及人员和商品规则管理。

## 默认登录

- 账号：`admin`
- 初始密码：取 `infra/.env` 中的 `ADMIN_PASSWORD`，未配置时为 `a123456`。

首次登录后请创建日常使用人员账号。生产环境建议下一版本增加“修改本人密码”页面。

## 部署

服务器更新方法见 `docs/交付部署说明.md`。升级脚本不会替换 `infra/.env` 和 `infra/data`。

## 后续接口预留

飞书多维表格、飞书机器人、微信小程序、拼多多/抖店开放平台属于下一阶段。当前 API 和数据库已按统一售后单结构设计，后续可在不重做前端主流程的情况下接入。
