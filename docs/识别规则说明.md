# 售后一句话识别规则说明

## 识别目标

从客服输入的一句话中提取：

- 订单号
- 平台
- 售后类型
- 商品型号
- 商品名称
- 数量
- 颜色
- 是否需要人工确认

## 平台判断

第一阶段按订单号格式判断：

- 拼多多：包含短横线，形如 `260708-560380003972903`。
- 抖店：纯数字长订单号，形如 `6953585234348872915`。
- 未识别：不符合已知规则时标记为 `未知平台`，需要人工确认。

后期接入平台 API 后，可通过订单号到拼多多/抖店接口查询确认。

## 售后类型判断

关键词：

- 补发：补发、补、重发、少发
- 换货：换货、换新、更换
- 退件：退件、退回、退货

## 数量判断

支持：

- 阿拉伯数字：`2个`、`5个`
- 中文数字：`两个`、`五个`
- 没有数量时默认 `1`

## 商品和颜色判断

先识别配件，再识别普通型号。

配件示例：

- `6600脚垫`：商品为 `6600脚垫`，无颜色。

普通型号示例：

- `6600灰`：型号为 `6600`，颜色为 `灰`
- `7001雨林绿`：型号为 `7001`，颜色为 `雨林绿`
- `210蛋白皮米白`：型号为 `210蛋白皮`，颜色为 `米白`

## 人工确认

以下情况需要人工确认：

- 未识别订单号
- 未识别平台
- 未识别商品
- 颜色有歧义，例如只写 `灰`，但该型号有多个灰色
