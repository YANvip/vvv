# 服务器部署说明

## 推荐长期部署方式

使用 GitHub 或 Gitee 保存完整代码。服务器只做拉取代码和启动服务。

## 第一次部署

```bash
cd /opt
git clone <你的仓库地址> after-sales-platform
cd /opt/after-sales-platform/infra
cp .env.example .env
```

编辑 `.env`，设置数据库密码和 Redis 密码。

创建网页登录密码：

```bash
echo "admin:$(openssl passwd -apr1 'a123456')" > nginx/.htpasswd
```

启动：

```bash
docker compose up -d
```

## 后续更新

```bash
cd /opt/after-sales-platform
git pull
cd infra
docker compose up -d --build
```
