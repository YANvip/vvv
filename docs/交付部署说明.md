# 交付版部署说明

## 更新现有服务器（保留数据库）

1. 把 `after-sales-platform.zip` 上传到服务器 `/opt/after-sales-platform.zip`。
2. 在服务器终端执行：

```bash
cd /opt
unzip -q -o after-sales-platform.zip -d after-sales-platform-upload
chmod +x after-sales-platform-upload/infra/deploy-update.sh
bash after-sales-platform-upload/infra/deploy-update.sh
```

3. 浏览器打开 `http://47.93.53.160`，按 `Ctrl+F5` 强制刷新。
4. 使用管理员账号登录：`admin` / `a123456`。

脚本会先备份当前代码，再替换应用文件；不会覆盖 `.env`，不会删除 `infra/data` 数据库目录。

## 第一次全新安装

```bash
cd /opt
unzip after-sales-platform.zip -d after-sales-platform
cd after-sales-platform/infra
cp .env.example .env
nano .env
docker compose up -d
docker compose ps
```

请在 `.env` 中修改数据库密码、Redis 密码和管理员初始密码。

## 检查运行状态

```bash
cd /opt/after-sales-platform/infra
docker compose ps
docker logs after_sales_api --tail=100
curl http://127.0.0.1:3000/api/health
```

健康接口正常时返回 `{"ok":true,...}`。

## 数据备份

```bash
docker exec after_sales_postgres pg_dump -U after_sales_user after_sales > /opt/after-sales-$(date +%Y%m%d).sql
```

建议每天定时备份，并把备份文件保存到另一台机器或阿里云 OSS。
