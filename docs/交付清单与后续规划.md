# 交付清单与后续规划

## 本次交付（1.0）

- 一句话识别：拼多多、抖店、淘宝/天猫订单格式。
- 售后类型：补发、换货、退件。
- 商品识别：型号、别名、数量、颜色、无需颜色的配件。
- 人工确认：识别结果可修改后建单，含灰色歧义提醒。
- 防重复：同一订单重复建售后单时提醒。
- 处理协作：客服建单、打单员扫码录入快递单号、管理员维护。
- 查询：关键词、状态、类型、平台组合筛选。
- 数据：详情修改、状态流转、操作日志、CSV 导出。
- 人员：账号、角色、启用/停用、本人修改密码。
- 商品：型号、别名、颜色和颜色必填规则。
- 运维：数据库持久化、自动升级、代码备份、数据备份说明。

## 上线后优先完善

1. 配置域名、ICP备案和 HTTPS，避免长期使用公网 IP。
2. 设置阿里云安全组只开放 22、80、443，数据库端口不对公网开放。
3. 配置每日数据库自动备份并异地保存。
4. 根据真实客服语料持续补充型号、颜色和别名规则。
5. 增加店铺资料、快递公司自动识别和批量打单列表。

## 第二阶段集成

1. 飞书多维表格：售后单创建和状态变化双向同步。
2. 飞书机器人：群内一句话建单、待确认提醒、超时提醒。
3. 微信小程序：客服移动录入、打单员扫码、进度查询。
4. 拼多多/抖店开放平台：订单号校验、订单商品和地址自动回填。
5. 消息队列和定时任务：接口失败重试、同步日志和异常告警。

## 正式业务仍需确认的数据

- 所有在售型号、完整颜色表和常用简称。
- 各平台订单号的真实样本与可能变化。
- 换货时“寄出单号”和“退回单号”的实际操作顺序。
- 退件是否需要退款状态、仓库验收结果和责任归属。
- 人员名单、店铺名单及每人可查看的店铺范围。
